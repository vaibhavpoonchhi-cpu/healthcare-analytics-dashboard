# Healthcare Analytics Dashboard

## Project Overview
This project analyzes healthcare patient records using Microsoft Excel. The objective is to clean raw data, summarize patient information, and present meaningful insights through an Excel dashboard.

## Tools & Technologies
- Microsoft Excel
- Power Query
- Pivot Tables
- Charts and Data Visualization
- KPI Reporting

## Project Workflow
1. Cleaned and standardized inconsistent data using Power Query.
2. Corrected data types and formatting.
3. Created Pivot Tables to summarize patient records.
4. Built KPI cards for total patients, average age, total billing, and average billing.
5. Designed charts to visualize medical conditions, gender distribution, admission types, and billing patterns.

## Key Analysis
- Patient count by medical condition
- Gender distribution
- Admission type analysis
- Average billing by medical condition
- Blood type distribution
- Overall healthcare billing metrics

## Files
- `Healthcare_Analytics_Dashboard.xlsx` — Excel workbook containing the cleaned data, Pivot Tables, and dashboard.
- `dashboard.png` — Dashboard preview screenshot (optional).

## How to Use
Download the Excel workbook and open it in Microsoft Excel to explore the dashboard and analysis.

## Skills Demonstrated
Excel, Power Query, Data Cleaning, Pivot Tables, Data Analysis, Data Visualization, Dashboard Development, and KPI Reporting.
